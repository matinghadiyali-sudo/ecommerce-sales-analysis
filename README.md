# E-Commerce Sales & Profit Trend Analysis (2023 - 2025)

##  Project Overview

This project focuses on cleaning, exploring, and analyzing an e-commerce transaction dataset containing 1,000 retail records across four major geographic regions. The goal is to uncover structural trends in retail profitability, analyze item distributions, and isolate outlier transactions that impact operational margins.

##  Tech Stack & Tools 

- **Data Engineering & Cleaning:** Python, Jupyter Notebook, Pandas
- **Statistical Modeling:** IQR (Interquartile Range) Method for Outlier Isolation
- **Business Intelligence & Visualization:** Power BI Desktop, Matplotlib

##  Key Insights Found

- Isolated and separated transaction anomalies using statistical filters:
  $$IQR = Q3 - Q1$$
- Found the highest-performing category by aggregate profitability.
- Structured data models optimized for seamless visualization import.
